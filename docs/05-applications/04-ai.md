# AI

Omabuntu preinstalls the major coding agents as commands you can run straight away.

| Command          | Tool                                                       |
| ---------------- | ---------------------------------------------------------- |
| `claude`         | [Claude Code](https://claude.com/claude-code) by Anthropic |
| `codex`          | [Codex](https://openai.com/codex) by OpenAI                |
| `gemini`         | [Gemini CLI](https://github.com/google-gemini/gemini-cli)  |
| `copilot`        | [GitHub Copilot CLI](https://github.com/features/copilot)  |
| `opencode`       | [opencode](https://opencode.ai), model-agnostic            |
| `pi`             | [pi](https://github.com/earendil-works/pi-coding-agent)    |
| `playwright-cli` | [Playwright](https://playwright.dev) browser automation    |
| `ghui`           | Pull request management TUI                                |

Each is a wrapper in `~/.local/bin`, not a globally installed package. The first run fetches the tool through `pnpm dlx` with a Node runtime managed by mise, so you always get the current version. Versions published in the last two hours are skipped.

## Running Agents Side by Side

The Tmux layout functions are built for this. From inside a project directory:

```bash
tdl claude          # editor left, claude right, terminal bottom
tdl claude codex    # same, with a second agent below the first
tsl 4 claude        # four panes, all running claude
```

See [Shell Functions](/manual/applications/shell-functions) for the full set.

## Adding Your Own

```bash
omakub npm install <package> [command-name]
```

The command name defaults to the package name. Pass the second argument when the binary is named differently, as with scoped packages.

## Ollama

For running models locally rather than through an API, install [Ollama](https://ollama.com) from _Install > AI > Ollama_ in the Omabuntu Menu.
